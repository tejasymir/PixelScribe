# PixelScribe

Turn screenshots into searchable knowledge.

PixelScribe is a Python-powered OCR utility that extracts text from images, saves it into text files, and makes it easy to search through previously captured information.

## Features

- Extract text from screenshots using OCR
- Process multiple images in batches
- Save extracted text as `.txt` files
- Search extracted text using keywords

## Built With

- Python
- Tesseract OCR
- Pytesseract
- Pillow
